## 💡 Quick Tips

### 1. Function Declarations
`def` is the standard function declaration keyword in Mojo 1.0.

### 2. Argument Conventions
Mojo uses `read` (default borrow), `mut` (mutable reference), `out` (output), and `var` (owned) argument conventions.

### 3. Python Integration
`from std.python import Python` - Call any Python library seamlessly.
